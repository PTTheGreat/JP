Sharkのメーカー保証を受けるには、必ず製品登録が必要なのですか。登録しないとどうなりますか。
整理すると2段構えです。メーカー保証2年は購入した時点で付きます。これに加えてSharkNinja公式オンラインストア(または公式楽天市場店)で購入した場合、商品到着後の製品登録でメーカー保証がプラス1年延長され合計3年になります。つまり登録が必須なのは延長分の1年で、忘れると延長が適用されない可能性があります。ただしリチウムイオンバッテリーとアクセサリーパックは延長の対象外です。登録の可否や期限は窓口(0120-522-552)で確認し、購入証明は必ず保管してください。 → 根拠となる事実を見る
