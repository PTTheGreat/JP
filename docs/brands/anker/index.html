Anker(アンカー)とはどんなブランドか

Ankerは中国・深圳発の充電関連機器ブランド。元Googleエンジニアが2011年に創業し、日本ではアンカー・ジャパン株式会社が販売・サポートを行う。モバイルバッテリー、充電器、ケーブルなど充電周辺機器が主力。
