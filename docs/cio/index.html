安全性・リコール3件

CIOのモバイルバッテリーは安全ですか?Ankerの方が安全だという見方は正しいですか?
「一方だけが危険」とする公的根拠はありません。両社とも国内正規流通の実績があり、モバイルバッテリーは電気用品安全法の対象でPSEマーク表示が求められます。重要なのは、リチウムイオン電池製品の発火リスクが特定ブランド固有ではなく業界共通だという点です。実際、CIO・Ankerの双方でモバイルバッテリーの一部型番について自主回収の事例があります【要確認】。したがって安全策は両ブランド共通で、PSEマーク付きの正規流通品を選ぶこと、購入後に公式サイトと消費者庁リコール情報サイトで型番を照合すること、膨張・異常発熱・異臭があれば直ちに使用を中止することの3点になります。 → 根拠となる事実を見る
