AmazonはAnkerの正規販売チャネルの一つであり、商品ページの「販売元」がAnker Japan(アンカー・ジャパン)となっている出品は公式の直販です。一方、Amazonには第三者による出品もあり、その全てが正規品とは限りません。確認のポイントは、(1)販売元の表示、(2)価格が相場から極端に安すぎないか、(3)モバイルバッテリー・充電器ならPSEマークと届出事業者名の表示があるか、の3点です。不安な場合は公式ストアや直営店、家電量販店での購入が確実です。 → 根拠となる事実を見る
Ankerの充電器が急速充電中にかなり熱くなります。また2ポート同時に挿すと充電が遅くなるのはなぜですか?
出力が下がるのは多くの場合が仕様です。複数ポートの充電器は各ポートの最大出力を単純に合計できず、同時使用時は合計出力の範囲内で配分される設計が一般的で、配分の組み合わせは製品ごとに決まっています。製品ページの出力仕様表を確認してください。発熱も、高出力時にある程度温かくなること自体は異常ではありません。ただし手で持てないほど熱い、異臭がする、筐体やプラグが変形・変色している場合は直ちに使用を中止しコンセントから抜き、保証期間内にサポートへ相談してください。 → 根拠となる事実を見る
2026年4月からモバイルバッテリーは飛行機に持ち込めなくなると聞きましたが本当ですか?
