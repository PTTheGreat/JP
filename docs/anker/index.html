充電器などで知られるAnker(アンカー)はどこの国の会社ですか?
Ankerは中国・深圳に本社を置くAnker Innovationsのブランドです。2011年に元Googleソフトウェアエンジニアのスティーブン・ヤン(陽萌)氏が創業し、2020年には中国・深圳証券取引所の創業板に上場しています。一方、日本国内での販売・保証・問い合わせ対応は、2013年に設立された日本法人「アンカー・ジャパン株式会社」が担当しています。つまり「本社と開発は中国、日本には販売とサポートを行う日本法人がある」という構造です。 → 根拠となる事実を見る
モバイルバッテリーのAnkerは信用できますか?中国製というのが気になります
「中国製かどうか」よりも、日本の安全規制に適合し国内で保証を受けられるかを基準に判断するのが実際的です。Ankerの日本正規品はモバイルバッテリーとして電気用品安全法(PSE)の対象で、PSEマーク表示のある製品が流通しています。また2013年設立の日本法人があり、日本語での保証・サポート窓口が国内にあります。過去に一部型番で自主回収の事例がありますが、公表して無償交換に応じる対応は制度が機能している一例と言えます。購入時は正規販売ルートを選び、型番が回収対象でないかを確認してください。 → 根拠となる事実を見る
Ankerが人気なのはなぜですか?中国企業なので国家情報法により情報が抜かれるのではと心配です
事実関係を分けて整理します。まず中国には国家情報法(2017年施行)が存在し、中国の組織・個人に国家の情報活動への協力を求める規定があると指摘されています。一方で、日本の公的機関がAnker製品を名指しで禁止・排除した措置は確認できていません【要確認】。またAnkerの主力である充電器・ケーブル・モバイルバッテリーは通信機能を持たず、データを外部送信する経路自体がありません。懸念がある場合は、通信を伴う製品ではアプリ権限とクラウド保存設定を見直す、といった対応が現実的です。 → 根拠となる事実を見る
Anker(アンカー)は危険なメーカーなのでしょうか?
日本の公的機関がAnkerを「危険なメーカー」と認定した事実は確認できていません【要確認】。ただし過去にモバイルバッテリーの一部型番で自主回収(無償交換)が実施された事例があり、これが「危険」というイメージの背景にあると考えられます。リチウムイオン電池を使う製品は、メーカーを問わず発熱・膨張のリスクがある製品カテゴリです。確認手順としては、手元の型番が消費者庁リコール情報サイトや公式の告知に載っていないかを見ること、膨張・異常発熱があれば直ちに使用を中止することが有効です。 → 根拠となる事実を見る
Ankerのモバイルバッテリーが米国ではリコール対象なのに、日本では対象外とされるのはなぜですか?
リコールは国ごとに制度・所管官庁・対象範囲が別々に決まるため、同じ製品名でも国によって対象範囲が異なることがあります。米国は消費者製品安全委員会(CPSC)、日本は消費者庁等が所管し、届出・公表の枠組みが異なります。また仕向地ごとに型番・製造ロット・セル供給元が異なる場合があり、不具合ロットが日本向けに流通していなければ日本では対象外となります。個別案件で日本向けに流通したロットの詳細は未確認です【要確認】。手元の製品は型番とシリアル番号を控え、公式告知と消費者庁サイトで照合してください。 → 根拠となる事実を見る
Ankerのモバイルバッテリーのリコールについて、自分が持っている製品も対象か確認する方法はありますか?
対象かどうかは「型番」と「シリアル番号」で判定するのが基本です。型番(A1000番台などのAから始まる型番)は本体側面や底面の印字、または外箱・購入時の注文履歴で確認できます。これを公式サイトのリコール・自主回収の告知ページに記載された対象型番・対象ロットと照合してください。あわせて消費者庁リコール情報サイトでも製品名や型番から検索できます。対象と判明した場合は直ちに使用を中止し、公式の受付窓口の案内に従ってください。対象外でも、膨張・異常な発熱・異臭がある場合は使用を止める判断が安全側です。 → 根拠となる事実を見る
Anker製品の保証は、公式サイトで買った場合だけ適用されるのですか?
公式サイト以外で購入した製品でも、正規の販売ルートで購入したものであればメーカー保証の対象となるのが一般的です。Ankerは公式ストアのほか、Amazon、楽天市場、家電量販店、直営店などで正規に販売されています。保証を受ける際は購入日と購入先を示す証明(レシート、注文履歴のスクリーンショット等)の提出を求められるため、必ず保管しておいてください。一方、フリマアプリでの個人間売買や、正規ルート外の並行品は保証対象外となる場合があります。保証期間や適用条件は製品により異なります【要確認】。 → 根拠となる事実を見る
Amazonで売られているAnker製品は本物ですか?偽物を避ける見分け方はありますか?
AmazonはAnkerの正規販売チャネルの一つであり、商品ページの「販売元」がAnker Japan(アンカー・ジャパン)となっている出品は公式の直販です。一方、Amazonには第三者による出品もあり、その全てが正規品とは限りません。確認のポイントは、(1)販売元の表示、(2)価格が相場から極端に安すぎないか、(3)モバイルバッテリー・充電器ならPSEマークと届出事業者名の表示があるか、の3点です。不安な場合は公式ストアや直営店、家電量販店での購入が確実です。 → 根拠となる事実を見る
Ankerのモバイルバッテリーが故障した場合、修理は受けられますか?
Ankerのアフターサービスは分解修理ではなく、交換対応が中心です。保証期間内に製品側の不具合と判断されれば、同等品への無償交換等で対応されるのが基本です。まずは日本法人のカスタマーサポート(メール・電話)に、型番・購入日・購入先・症状を伝えて相談してください。保証期間を過ぎている場合の扱いや、内蔵リチウムイオン電池のみの交換サービスの有無については、本サイトでは確認できていません【要確認】。なお膨張や異常発熱がある製品は使用を中止し、自治体等の回収ルールに従って処分してください。 → 根拠となる事実を見る
Ankerのモバイルバッテリーで、PSEマークはどこに表示されていますか?
モバイルバッテリーのPSEマークは、本体に直接印字またはラベル表示され、丸型(円形)の中に「PSE」と書かれた記号です。モバイルバッテリー(リチウムイオン蓄電池)は「特定電気用品以外の電気用品」に区分されるため丸型で、ACアダプタなど「特定電気用品」に区分される機器はひし形のPSEマークになります。マークの近くには届出事業者名が併記されます。表示位置は底面や側面など機種により異なり、印字が小さい場合もあります【要確認】。本体で見つからない場合は外箱や取扱説明書も確認してください。 → 根拠となる事実を見る
