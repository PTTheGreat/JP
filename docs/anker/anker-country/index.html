Ankerは中国・深圳に本社を置くAnker Innovationsのブランドです。2011年に元Googleソフトウェアエンジニアのスティーブン・ヤン(陽萌)氏が創業し、2020年には中国・深圳証券取引所の創業板に上場しています。一方、日本国内での販売・保証・問い合わせ対応は、2013年に設立された日本法人「アンカー・ジャパン株式会社」が担当しています。つまり「本社と開発は中国、日本には販売とサポートを行う日本法人がある」という構造です。
