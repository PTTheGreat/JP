掃除機のダイソンはどこの国のメーカーで、どこで製造しているのですか?
ダイソンはイギリス発祥のメーカーで、現在の本社機能はシンガポールにあります。米国のメーカーではありません。1991年にジェームズ・ダイソン氏が英国で創業し、2019年に本社を移転しました。製造は英国内ではなく、マレーシアやフィリピンなどアジアの工場が中心で、型番によっては中国製もあります【要確認】。ブランドの国と製造国は別なので、原産国は外箱の表示で確認してください。日本法人は1998年設立です。 → 根拠となる事実を見る
ダイソンの掃除機は中国製なのですか?
型番によります。ダイソンは英国発祥・本社シンガポールの企業で、製造は海外の自社・委託工場が担っています。主力はマレーシアやフィリピンですが、一部の型番は中国の工場で生産され、その場合は外箱やカタログに中国製と表示されます【要確認】。カタログに中国製とあれば、その型番はその通りです。ただし製造国にかかわらず、日本の正規流通品であればPSEマークの表示や国内の保証条件は同じ扱いになります。 → 根拠となる事実を見る
ダイソンの掃除機の保証はどうなっていますか?高価なので故障時が心配です
日本の正規品は、コードレス掃除機・ヘアケアともにメーカー保証2年が基本です(製品により異なる場合あり)【要確認】。期間内の自然故障は無償修理・交換の対象ですが、落下や水濡れなどの過失、消耗品(バッテリー・フィルター)の経年劣化は対象外となるのが一般的です【要確認】。ダイソンは国内に修理サービスセンターと日本語窓口を持ちます。保証適用にはレシート等の購入証明が前提なので必ず保管してください。 → 根拠となる事実を見る
購入から3年でダイソンのドライヤーが故障しました。修理は定額料金になるのですか?
修理費用の金額は本サイトでは断定できず、公式サポートで要確認です【要確認】。ヘアケア製品の保証は2年が基本のため、購入から3年経過した個体は保証外となり有償対応になります【要確認】。有償修理では箇所ごとの見積もりではなく、製品単位の定額料金(整備済品との交換を含む形)で案内される場合もあります【要確認】。購入日と型番を用意して公式サポートに確認し、金額次第では買い替えも選択肢になります。 → 根拠となる事実を見る

ダイソンの国内正規品と、USA正規品などの並行輸入品では何が違いますか?
最大の違いは、日本国内でメーカー保証と修理を受けられるかどうかです。ダイソンの保証は購入国と正規販売ルートを前提とするため、海外仕様の並行輸入品は日本では保証対象外として扱われるのが一般的です【要確認】。米国向けは120V仕様で日本の100Vでは性能が出ず、PSEマークや無線機能付き機種の技適表示がない可能性もあります。購入前に販売店へ国内正規保証の有無とPSE表示・国内窓口を確認してください。 → 根拠となる事実を見る
