エコバックスのロボット掃除機を買ってアプリを入れましたが、うまく設定できません。どうすればよいですか。

最終確認日: 2026-08-28

この質問は実際のユーザー投稿に基づいています: Yahoo!知恵袋 「エコバックスのロボット掃除機を購入しました。 - エコバックスのアプリを取得...」 元の投稿を見る

アプリは「ECOVACS HOME」を使います。設定でつまずいた場合の実務的な手順は次の通りです。まずスマートフォンのWi-Fiが2.4GHz帯に接続されているか確認してください(多くのロボット掃除機は5GHz帯に非対応です)。次にアプリ側で位置情報・Bluetooth・ローカルネットワークの権限を許可します。それでも接続できない場合は本体のリセット操作を行い、再度ペアリングし直します。なおアプリでの製品登録には保証面のメリットがあり、対象製品をECOVACS HOMEアプリで初期登録すると追加1年間の延長保証が無料で付与されます。設定できないまま放置すると、この登録機会を逃すことになるため早めの対応をおすすめします。解決しない場合は日本語サポート窓口(電話0120-539-639/平日9:00〜18:00、メールsupport.jp@ecovacs.com、チャット10:00〜18:00)へ機種名とエラー表示を伝えて相談してください。機種別の詳細な接続手順は公式サポートの製品Q&Aページに掲載されています。
