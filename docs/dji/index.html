DJIという中国のメーカーはどのような企業ですか?
DJIは中国・深圳に本社を置くドローン・映像機器メーカーです。正式社名はSZ DJI Technology Co., Ltd.(深圳市大疆創新科技有限公司)で、2006年に汪滔(フランク・ワン)氏が創業しました。民生用ドローンで世界シェア首位とされ、Osmoシリーズのジンバル・アクションカメラや農業用ドローンにも展開しています。非上場のため売上高や従業員数の公開は限定的です。日本には「DJI JAPAN株式会社」があり、日本語サポートと国内修理受付に対応しています。日本正規品は技適取得済みですが、海外版は未取得の場合があります。 → 根拠となる事実を見る
アメリカがDJI製ドローンを規制して使わなくなったというのは本当ですか?
米国で政府調達からの排除等の措置が取られている点は事実ですが、「アメリカ全体で使用禁止」と断定できるかは公開情報からは確認できません【要確認】。措置の中心は連邦政府機関の調達・運用や特定の補助対象からの除外であり、民間の一般利用まで一律に禁止されているかは各時点の法令で個別確認が必要です【要確認】。日本国内では民間利用に対する同種の禁止措置は確認されていません【要確認】。ただし日本では航空法により100g以上の機体に機体登録とリモートID搭載が義務づけられており、国内独自のルールが適用されます。 → 根拠となる事実を見る
DJIの製品とアプリの安全性はどう考えればいいですか?
公開情報から整理できる事実は3点です。第一に、米国では政府調達からの排除等の措置があります。第二に、日本国内では民間利用に対する同種の禁止措置は確認されていません【要確認】。第三に、日本正規品は技適・PSEなど製品側の国内法規制に適合しています。一方、アプリが取得する権限や通信データの送信先といった実装の詳細は公開情報だけでは検証できません【要確認】。インストール時の権限要求とプライバシーポリシーを確認し、業務利用や勤務先の端末に導入する場合は会社のIT規程に従って判断してください。 → 根拠となる事実を見る

中国で購入したDJI製ドローンを日本に持ち帰って使えますか?
海外版をそのまま日本国内で飛ばすと法令違反となるおそれがあります。理由は2点です。第一に電波法で、操縦や映像伝送に電波を使う機器は技術基準適合証明(技適)が必要です。技適未取得の無線機器を国内で使用すると電波法違反となるおそれがあり罰則の対象です。海外版は未取得の場合があるため型番ごとの確認が必要です。第二に航空法で、100g以上の機体は購入国を問わず国交省への機体登録とリモートID搭載が義務です。加えて海外購入品は国内の保証・修理の対象外となる場合があります【要確認】。 → 根拠となる事実を見る
中国のドローン企業DJIは株式を上場していますか?
DJIは非上場です。中国・深圳に本社を置く未上場企業で、株式市場で売買できる銘柄としては公開されていません。非上場のため売上高・利益・従業員数といった財務情報の公開は限定的です。日本の証券会社を通じて「DJI株」として購入できる商品があるかも公開情報では確認できません【要確認】。なお同じ深圳のカメラメーカーでも、Insta360を展開する影石創新は2025年に上海証券取引所の科創板(STAR Market)へ上場しており、上場状況は企業ごとに異なります。 → 根拠となる事実を見る
DJIの日本未発売ドローンを個人輸入した場合、日本国内で使えますか?
輸入や所持自体は可能ですが、そのまま国内で飛ばせるとは限りません。電波を使う機器は電波法上の技適が必要で、技適未取得の無線機器を日本国内で使用すると電波法違反となるおそれがあり罰則の対象です。日本未発売モデルは技適未取得のことが多いため、総務省の技適検索で型番ごとに確認してください。さらに100g以上の機体は航空法により国交省への機体登録とリモートID搭載が義務で、DID上空・空港周辺・夜間等はDIPSでの許可承認が必要です。国内の修理・保証の対象外となる場合もあります【要確認】。 → 根拠となる事実を見る
DJI製品を公式に修理に出したいのですが、日本では修理を受け付けていますか?
