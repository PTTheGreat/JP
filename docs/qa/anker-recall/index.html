Ankerのモバイルバッテリーにリコール(回収)はありますか?

はい、Ankerのモバイルバッテリーは一部型番で自主回収が実施された事例があります。対象は特定の型番・製造ロットに限られ、全製品が対象ではありません。手元の製品が対象かどうかは、消費者庁リコール情報サイトまたはAnker Japan公式サイトで型番を確認してください。対象製品は無償交換等の対応が案内されています。
